PROJECT OVERVIEW

Library Book Recommendation System

A beginner-friendly web application that helps readers discover books by searching, selecting a genre and choosing a reading mood.

Problem statement

Readers may find it difficult to choose a book from a large collection. This project provides a simple way to explore and filter a sample book library.

Objectives

  • Organise book information.
  • Search by title, author or genre.
  • Filter by genre and mood.
  • Recommend higher-rated matching books.
  • Store book and feedback data in SQLite.

Technologies used

Python, Flask, SQLite, HTML, CSS, JavaScript and Jinja2 templates.

How recommendation works

The user selects a genre and mood. The application filters books that match those choices and sorts the results by sample rating, from highest to lowest.
